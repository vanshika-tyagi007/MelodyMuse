# 🎵 Music App

A modern, responsive music streaming web application that delivers an intuitive and immersive music listening experience. The application features a clean interface, seamless navigation, and responsive design for desktop and mobile users.

## 🌐 Live Demo

https://music-app-4a8c1.web.app/

## ✨ Features

- 🎧 Modern music player interface
- 🔍 Search functionality
- 📱 Fully responsive design
- 🎵 Browse songs and playlists
- ▶️ Music playback controls
- ❤️ User-friendly UI/UX
- ⚡ Fast loading performance
- ☁️ Firebase Hosting

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Deploy to Firebase

```bash
firebase deploy
```
